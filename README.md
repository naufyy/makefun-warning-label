# Warning Label for Humans

This is my entry for the make.fun contest "Warning Label for Humans: One Line, Big Laugh". It is a single safety warning, written in the plain voice of a real printed label, about a habit nearly everyone shares: opening the fridge at 2 a.m., finding nothing new, and doing it again ten minutes later. The joke lands in the last few words. `candidates.txt` holds six drafts with the one I chose first.

## Run it

```
python3 main.py
```

This writes the label to `/output/entry.txt`.
